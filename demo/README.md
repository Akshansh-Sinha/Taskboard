# Demo Deliverables

This directory contains the presentation deck, architecture diagrams, and walkthrough video for the final capstone project.

## Contents

- **`Taskboard_DevOps_Architecture_and_Walkthrough.pptx`**: Presentation slides covering the application architecture, testing, Docker setup, CI/CD pipeline, Terraform config, Kubernetes/Helm deployment, and monitoring.
- **`taskboard_command_walkthrough.mp4`**: Terminal walkthrough video demonstrating the project commands being run (tests, build, container checks, terraform validate, helm lint, kubectl resources, metrics).
- **`assets/`**: Architecture and workflow diagrams used in the presentation deck.
